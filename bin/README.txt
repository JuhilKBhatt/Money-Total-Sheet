Money Total Sheet / Accounts Dues Manager - Portable Node Runtimes
===================================================================
If target machines do not have Node.js installed, you can drop:
1. macOS Node binary: bin/mac/node
2. Windows Node executable: bin/windows/node.exe

When present, the macOS mac-run.command launcher and Windows windows-run.bat launcher will
automatically use these bundled binaries with zero installation required!
